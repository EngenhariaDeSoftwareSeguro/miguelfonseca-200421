Users
- POST /user — create user (no auth required)
- GET /user/{userId} — get user by id
- DELETE /user/{userId} — delete user
- POST /login — log in, returns Bearer <username> token (no auth required)

Music lists
- POST /musiclist — create a list ({"listName": "..."}), owned by the authenticated user
- GET /musiclist — get all lists owned by the authenticated user
- GET /musiclist/{listId} — get one list (must own it)

Music items
- POST /music/item — create an item ({"album": "...", "artist": "...", "listId": N}), must own the list
- GET /music/{listId}/items — get all items in a list, must own the list
- GET /music/{listId}/items/{musicId} — get one item, must own the list
- DELETE /music/{listId}/items/{musicId} — delete an item, must own the list
